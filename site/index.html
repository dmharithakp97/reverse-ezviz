H-2 lab · encrypted-media weakness

the verification code IS the key, and every file carries an offline oracle — try it
Oracle demo

Each encrypted blob stores MD5(MD5(verifyCode)). That tag lets an attacker confirm a guessed code with two hashes — no device, no server. Type a code, then let the browser brute-force it back.

Live demo brute-forces up to 4 chars (26⁴ ≈ 457k) to stay responsive. Real codes are 6 chars — see the calculator for how fast that falls on a GPU.

Custom STUN / NAT header

ezviz_stunclient::CStunProtocol — not RFC 5389. 32-byte big-endian header (recovered from ComposeMsgHeader), TLV body, CRC32 trailer.

SADP LAN surface

Hikvision multicast 239.255.255.250:37020. The same protocol that discovers cameras also controls them:

Enumerate devicesSADP_SendInquiry
Own a factory-inactive unitSADP_ActivateDevice
Password reset flowsSADP_ResetPasswd_V40/V50
Rewrite network configSADP_ModifyDeviceNetParam

Anyone on the L2 segment can inventory and potentially activate cameras. Mitigate: VLAN-segment, block multicast 37020, activate before deployment.

KeyProtect white-box · obfuscation, not crypto

libencryptprotect.so (9.5 KB, no cipher — memcpy/sprintf/base64 only) builds a hardcoded constant on the stack. Recovered value, whose printable bytes spell the vendor's home city:
